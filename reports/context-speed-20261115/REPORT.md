# WexPack: ускорение контекстного кодера без изменения архивов

15 ноября 2026. База — `4c54031`, контекстные литералы и четыре recent-расстояния.
Сжатие, модели и wire-формат не урезаны: все **42 пары архивов побайтно совпали**.
Все **84 распаковки** сверены по полному списку путей, размерам и SHA256.
Это before/after-сравнение WexPack, а не новые замеры ZIP/RAR/7z. Их размеры из
[предыдущего отчёта](../context-20261115/REPORT.md) не меняются при идентичных байтах WXP;
победа над RAR/7-Zip на исходниках/ELF всё ещё не достигнута.

## Что убрано

- Четыре повторных кодирования потоков типов, длин, расстояний и дополнительных
  битов из пяти проб контекста. Теперь одна общая часть и пять пакетов литералов.
- Повторная нормировка частот после rANS-кодирования: кодер возвращает реально
  использованную модель. Raw-буфер создаётся только при выборе raw.
- Перебор невозможных слотов длины и повторный расчёт цены расстояния для каждой
  длины. Существующие слот-концы и полный match посещаются в прежнем порядке;
  дублированный полный match при точном слот-конце пропускается без смены tie-break.
- Повторный поиск уже рассчитанного lookahead после выбора литерала. Позиция,
  словарь и recent-state в этом случае не изменились относительно lookahead.

Порядок моделей, нормированные цены, все match-кандидаты, глубина поиска,
ограничения DP, границы истории и условия выбора payload прежние. Формат остаётся
WXE1/2/3/4 и WXS1/2, кодеки 0..5. Новых обязательных флагов нет. Короткие записи
литералов занимают 3 байта каждая: максимум 262144 записи (768 КиБ) на блок.
Побеждающий меньший пакет перемещается в уже выделенном буфере без роста.

## Проверка сохранения результата

Две дополнительные unit-проверки сравнивают с полными исполняемыми функциями,
замороженными до оптимизации и доступными только под cfg(test). Проверяются:

- Весь payload, числа токенов/совпадений, контекст и все таблицы цен.
- Пустые/короткие/случайные/текстовые данные, literal-only и настоящий LZ-разбор,
  все пять моделей, произвольное начало с историей.
- Все токены lazy-разбора на уровнях 4/5/7 для старой и новой схем расстояний.
- Реальные архивы на семи наборах, обычный/solid, 42 совпадения SHA256 из 42 пар.
- Малый отдельный CLI-набор: уровни 1/4/7/8/9 в обоих режимах дают одинаковые байты.
- Старые WXE1/2/3 и encrypted-архивы, взаимное чтение WXE4, штатные тесты crypto/FEC.

## Методика

84 измеренных pack/unpack пары: 7 наборов × 4 профиля × 3 повтора. Профили:
старый/новый WXP, обычный/solid; `-l5 --dedup --threads 4 --memory-mib 512`.
Последовательный перемешанный порядок seed=2026111502; каждый профиль прогрет.
Физические CPU [0,2,4,6], nice=5. Замороженный корпус из предыдущих отчётов.
Кэш ОС не очищается, рабочий стол работает. Измеряется вся команда, включая I/O
и fsync. Проверка извлечённых файлов выполняется вне таймера. Во время замеров
сборки и тесты не запускались. Наборы копий, чисел и random синтетические.
Все архивы без encryption/recovery для измерения скорости; эти функции проверены отдельно.
